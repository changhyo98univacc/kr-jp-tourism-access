# _meta — 근거 대장

> 이 폴더는 **주장과 근거를 잇는 대장**이다. 사람도 기계도 읽는다.
> 구조는 `AgentArmory/rules/paper_project_template.yaml` §ledger_grades 를 따른다.

| 파일 | 무엇 |
|---|---|
| `lineage.csv` | 산출물 계보. 무엇이 무엇으로 어떻게 만들어졌나 |
| `claims.csv` | 주장-근거. 어느 주장이 어느 파일에 기대나 |

## 무엇에 쓰나

발표 자료를 만들 때 `AgentArmory/tools/deck_check.py` 가 이 두 파일을 읽는다.
슬라이드가 `@ 근거 annual.csv` 처럼 인용하면 등급을 대조해서, **재현 못 하는 것을
슬라이드에 넣으면 오류로 잡는다.**

발표 폴더의 `deck.yaml` 에 이렇게 적어야 작동한다:

```yaml
근거출처: "../../_meta"
```

**claims** — 확정 / 근거대기 / 근거부족 / 폐기

## `재현가능` 의 범위 — 반드시 읽을 것

지금 11개 산출물이 전부 `재현가능` 이다. 다만 **이 컴퓨터에서** 그렇다.

`data/raw/` 는 `.gitignore` 에 들어 있어 저장소에 없고, 항공통계 48개 엑셀은
`docs/DATA_SOURCES.md` 에 **해시도 크기도 적혀 있지 않으며** 공공데이터포털에
로그인해 월별로 수동 조회해야만 받을 수 있다. 저장소만 받은 사람은 원자료부터
다시 만들지 못한다.

숙박통계·공항좌표·경계 3종은 해시와 직링크가 있어 그대로 다시 받을 수 있다.
